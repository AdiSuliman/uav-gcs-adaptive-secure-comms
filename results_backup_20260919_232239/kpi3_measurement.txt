CAVEAT: agreement compares only the chosen ACTION NAME between policies.
rule_based_policy.m's own per-threat mitigation_db values are computed but
never applied to any BER calculation -- both policies' physical mitigation
effect goes through the same action_mitigation_db (25/15/25/25 dB). This is
a decision-policy comparison, not two independently-realized countermeasure
systems (see docs/DECISIONS.md).

Interpretation: Rule-Based is effectively instant (a dB lookup); DQN costs a
few ms of real neural-network inference. This is the genuine speed trade-off
of using a learned policy over a static one in this system -- DQN's value is
not faster convergence (both converge in 1 step) but rather the potential to
learn better-than-rule-based action choices from data (measured separately as
recovery%% and agreement rate above).
